A topologia só pode ser desenhada depois do G1. O número de interfaces livres em cada roteador limita quantos vizinhos ele pode ter.
</Callout>

## Ferramenta

Cadastre os enlaces na tabela de rotas previstas. O InfraLab calcula, a partir deles, os saltos até SP, a rota primária, a de contingência e os empates.

## Procedimentos previstos

1. Identificar os vizinhos de cada roteador.
2. Definir os enlaces físicos (cada ilha com no mínimo dois vizinhos).
3. Planejar o endereçamento dos enlaces e das LANs.
4. Calcular os caminhos primário e de contingência.
5. Contar os saltos até SP.
6. Identificar possíveis empates de métrica.
