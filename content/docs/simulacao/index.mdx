**Entrega:** arquivo `.pkt` + evidências (prints de `show ip route` e `tracert`). **Ponto de controle G3:** simulação validada.

A rede inteira roda em um único arquivo `.pkt` (roteadores 2811 com módulos seriais), com os mesmos endereços e as mesmas rotas previstas.

## Procedimentos previstos

1. Montar a topologia no Cisco Packet Tracer.
2. Configurar os roteadores.
3. Configurar RIP v2.
4. Configurar a rota padrão.
5. Verificar as tabelas de roteamento.
6. Executar traceroute.
7. Simular a falha de enlaces.
8. Verificar convergência e rotas alternativas.

```bash title="Cisco IOS · Comandos de referência"
show ip route
show ip protocols
show running-config
```

<Callout type="warn">
Use o simulador para validar **caminhos**, não tempos: o Packet Tracer converge diferente do equipamento real. As configurações só serão apresentadas depois da aprovação da topologia (G2).
</Callout>
